Embroidery Digitizing: Industrial Workflow & Terminology

刺绣制版：工业流程与术语

Research basis for the open_emby product design: how a professional embroidery digitizer (制版师) actually works — from artwork to machine file — and how each step maps to our AI Agent, Rust core, and ComfyUI pipeline. Sources: Wilcom / Tajima DGML workflows, industry digitizing guides (Impressions, DigitEMB, digitizing cheat sheets), and CN industry usage (电脑绣花打版).

本文是 open_emby 产品设计的调研基础：专业刺绣制版师从图稿到机器文件的真实工作流， 以及每一步如何映射到我们的 AI Agent、Rust 核心与 ComfyUI 流水线。 来源：Wilcom / Tajima DGML 工作流、行业制版指南（Impressions、DigitEMB、制版速查表）与中文行业用法（电脑绣花打版）。

01The Digitizer's Workflow (制版师工作流)

01制版师工作流（The Digitizer's Workflow）

The industrial loop a puncher/digitizer follows in Wilcom, Tajima DGML or similar suites. Each stage lists its open_emby owner: UI ComfyUI Rust core AI Agent Manual/Factory.

制版师在 Wilcom、Tajima DGML 等软件中的工业闭环。每个阶段标注 open_emby 的负责模块： UI ComfyUI Rust 核心 AI Agent 人工/工厂。

1 · Artwork Intake & Evaluation / 图稿导入与评估

1 · 图稿导入与评估 / Artwork Intake & Evaluation

UIAI Agent

Accept any artwork (PNG/JPG/SVG/photo/scan). The digitizer evaluates: target size (mm), fabric & stabilizer, stitch-count budget, and whether the art is even "stitchable" — fine gradients, hairline details and small text must be simplified or dropped.

接收任意图稿（PNG/JPG/SVG/照片/扫描件）。制版师评估：目标尺寸（毫米）、面料与底衬、 针数预算，以及图稿是否"可绣"——细渐变、发丝级细节和过小文字必须简化或舍弃。

In: any image → Out: evaluation notes + target spec
输入：任意图片 → 产出：评估说明 + 目标规格

2 · Artwork Cleanup & Color Blocking / 图稿整理与色块分离

2 · 图稿整理与色块分离 / Cleanup & Color Blocking

ComfyUIRust coreAI Agent

Simplify the artwork into flat color blocks matching the thread palette: reduce colors to the machine's practical limit, flatten gradients, remove noise. This is where our img2img stylization lives — an AI "stylize to flat color blocks" pass, followed by hard color quantization (Lab KMeans in Rust) that locks every pixel to a thread color.

把图稿整理成与绣线色板对应的平涂色块：减色到机器实用上限、压平渐变、去噪。 我们的图生图风格化就在这一步——AI"平涂色块化"先行，再由 Rust 的 Lab KMeans 硬量化把每个像素锁定到绣线色。

In: raw image → Out: flat-color artwork + thread palette
输入：原图 → 产出：平涂色块图稿 + 绣线色板

3 · Object / Region Segmentation / 对象与区域划分

3 · 对象与区域划分 / Object Segmentation

Rust coreAI AgentUI

Split color blocks into stitchable objects (regions) with clean boundaries. A digitizer thinks in objects, not pixels: each object gets its own stitch type, direction and density.

把色块进一步拆成边界干净的可绣对象（区域）。制版师的思维单位是对象而非像素： 每个对象拥有自己的针法、方向和密度。

In: flat artwork → Out: region list (mask, bbox, area)
输入：平涂图稿 → 产出：区域列表（掩码、包围盒、面积）

4 · Stitch Type Assignment / 针法分配

4 · 针法分配 / Stitch Type Assignment

AI AgentUI

The core craft decision per object: SATIN 缎面针 for narrow columns/borders/lettering, TATAMI / FILL 榻榻米(填针) for large areas, RUN 平针 for outlines/fine lines, plus special techniques APPLIQUÉ 贴布绣 · 3D PUFF 立体绣 · SEQUIN 珠片绣.

对每个对象做核心工艺决策：缎面针 SATIN 用于细长条/边框/文字， 榻榻米（填针）TATAMI 用于大面积， 平针 RUN 用于轮廓/细线，特殊工艺 贴布绣 · 立体绣 · 珠片绣。

In: regions → Out: stitch type per region
输入：区域列表 → 产出：每区域针法

5 · Density, Underlay & Compensation / 密度、打底与补偿

5 · 密度、打底与补偿 / Density, Underlay & Compensation

AI AgentRust core

Per-object parameters: stitch density (mm spacing), stitch length, underlay (打底针 — edge-walk / zigzag / tatami underlay that stabilizes fabric), pull compensation (拉伸补偿 — over-sizing to counter fabric gathering), and push-pull handling. Wrong values cause puckering (起皱) or gaps (露底).

逐对象参数：针迹密度（毫米针距）、针长、打底针（边缘走针/锯齿/榻榻米打底，稳定面料）、 拉伸补偿（放大轮廓以抵消面料收缩）与推拉变形处理。参数错误会导致起皱或露底。

In: typed regions + fabric → Out: parameterized objects
输入：带针法的区域 + 面料 → 产出：参数化对象

6 · Pathing & Sequencing / 走针顺序与路径规划

6 · 走针顺序与路径规划 / Pathing & Sequencing

Rust coreAI Agent

Order objects to minimize jump stitches (跳针), trims (剪线) and color changes (换色); stitch background-to-foreground, center-out, bottom-up. Registration (对位/套准) between colors depends on pathing quality. This is the highest-skill step — and the best optimization target for our Rust core.

规划对象顺序以最小化跳针、剪线和换色次数；先背景后前景、由内向外、自下而上。 多色对位（套准）质量取决于路径规划。这是制版师技术含量最高的一步，也是 Rust 核心的最佳优化目标。

In: parameterized objects → Out: ordered stitch sequence
输入：参数化对象 → 产出：有序针迹序列

7 · Simulation Preview & Local Editing / 仿真预览与局部修改

7 · 仿真预览与局部修改 / Simulation & Local Editing

UIComfyUIRust core

Preview the stitch-out (TrueView / 针迹仿真), then iterate locally: select a region and repaint it (inpaint 局部重绘), adjust a color, fix a letter. Every edit re-runs only the affected pipeline slice.

预览绣出效果（针迹仿真），然后局部迭代：选区重绘（inpaint）、改色、修字。 每次修改只重跑受影响的流水线切片。

In: stitch sequence → Out: revised artwork/params
输入：针迹序列 → 产出：修订后的图稿/参数

8 · Machine File Export + Worksheet / 机器文件导出 + 生产单

8 · 机器文件导出 + 生产单 / Export + Worksheet

Rust coreUI

Write machine formats (DST/PES/JEF/EXP/…), plus the production worksheet (生产单/工艺单): thread color chart with brand codes (Madeira/Gunold/…), color change order, stitch count, size, hoop and stabilizer notes.

写出机器格式（DST/PES/JEF/EXP…），并附生产单（工艺单）：绣线色卡（含品牌色号）、 换色顺序、针数、尺寸、绣框与底衬说明。

In: final sequence → Out: design.dst + worksheet.pdf
输入：最终序列 → 产出：design.dst + 生产单

9 · Test Sew-out & Revision / 试绣打样与改版

9 · 试绣打样与改版 / Test Sew-out & Revision

Manual/FactoryAI Agent

Run a physical sample (试绣/打样), inspect puckering, coverage, registration, then revise (改版) density/pathing. The machine-run verdict (success/failed + reason) feeds our data flywheel as ground truth for the digitizing policy.

上机试绣打样，检查起皱、覆盖度、对位，然后改版调整密度/路径。 上机结果（成功/失败+原因）作为 ground truth 回流数据飞轮，用于制版策略学习。

In: machine file → Out: verdict + revised file
输入：机器文件 → 产出：结论 + 修订文件

Stitch Types / 针法

针法 / Stitch Types

EN中文Use用途
Satin stitch缎面针 / 缎纹针 Narrow columns, borders, lettering. Zigzag across the column. 细长条、边框、文字。横跨条带的锯齿针。
Tatami / Fill stitch榻榻米 / 填针 Large areas; rows of running stitches in a weave pattern. 大面积填充；按编织纹理排列的平针行。
Run(ning) stitch平针 / 直线针 / 走针 Outlines, fine lines, travel between objects. 轮廓、细线、对象间走线。
Bean / Triple run三针平针 / 加强平针 Back-and-forth run for bolder lines.来回走针加粗线条。
Backstitch / Stem stitch轮廓针 / 茎绣针 Hand-look outlines and stems.手绣感轮廓与枝干。
Underlay打底针 / 下缝 Foundation stitches under satin/tatami: edge-walk, zigzag, tatami underlay. 缎面/填针下的基础针：边缘走针、锯齿打底、榻榻米打底。
Appliqué贴布绣 Fabric patch stitched down; placement/tack-down/finish lines. 缝贴布块：定位线/压布针/完成线三步。
3D Puff立体绣 Foam under dense satin for raised effect (caps). 泡沫衬垫 + 高密缎面，帽绣常见。
Sequin / Chenille珠片绣 / 毛巾绣 Special machine heads; sequin devices, loop chenille. 特种机头：珠片装置、毛巾绣线圈。

Parameters & Defects / 参数与疵病

参数与疵病 / Parameters & Defects

EN中文Notes说明
Stitch density针迹密度 Spacing between stitch rows (mm); typical satin 0.35–0.45mm, tatami 0.4–0.5mm. 针迹行距（毫米）；缎面常用 0.35–0.45mm，榻榻米 0.4–0.5mm。
Stitch length针距 / 针长 Length of a single stitch; max ~12.1mm in DST. 单针长度；DST 上限约 12.1mm。
Pull compensation拉伸补偿 Over-size objects to counter fabric pull-in. 放大对象以抵消面料收缩。
Push-pull distortion推拉变形 Stitches push fabric along stitch direction, pull across it. 针迹沿走向推布、垂直方向拉布造成变形。
Jump stitch / Trim跳针 / 剪线 Travel moves; long jumps auto-trim. Minimize both. 空走针；长跳针自动剪线。两者都应最小化。
Color change换色 Thread swap command; ordering defines the worksheet. 换线指令；其顺序即生产单换色表。
Registration对位 / 套准 Alignment between colors; poor pathing breaks it. 多色间的对齐；路径差会错位。
Puckering起皱 Fabric gathering from over-density or no underlay. 密度过大或缺打底导致面料起皱。
Stitch count针数 Total stitches; drives machine time & price. 总针数；决定工时与报价。
