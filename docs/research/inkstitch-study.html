Ink/Stitch 研读笔记 — 开源制版系统拆解

仓库：github.com/inkstitch/inkstitch（Inkscape 扩展，GPL v3）。 本地参考副本：E:\Project-刺绣机\reference\inkstitch（浅克隆，仅作算法学习，不进入产品代码）。 它是目前最成熟的开源刺绣制版系统，针迹算法经过大量生产验证 —— 我们的 crates/emby-core 针迹生成的进化路线以此为准。

01架构总览

Ink/Stitch 模块职责我们的对应物
lib/elements/元素层：FillStitch / SatinColumn / Stroke，参数化 + 校验制版方案 regions（要升级为元素模型）
lib/stitches/针迹算法：tatami_fill / auto_satin / running_stitch / contour_fill 等 12 种crates/emby-core/src/stitch.rs
lib/stitch_plan/针迹序列模型：Stitch / StitchGroup / ColorBlock / LockStitchStitchPoint / StitchResult
lib/extensions/工序编排：params / simulator / output / letteringsidecar + Electron 工作台
pyembroidery（依赖）机器格式编解码 DST/PES/JEF…crates/emby-core/src/dst.rs（自研）
依赖启示 — Ink/Stitch 的几何全靠 shapely（GEOS）做多边形运算：扫描线求交、 buffer 缩扩、连通域、合法性修复。Rust 侧对应物是 geo crate（或 geo-boolop/i_overlay 做布尔运算）。 引入几何库是针迹生成进阶的前提。

02tatami_fill 算法精要（fill.py）

pipeline：intersect_region_with_grating → pull_runs → section_to_stitches

  1. 格栅求交 — 以任意角度生成平行扫描线，与多边形求交得到每行的填充段（我们当前只支持水平行， 且工作在像素栅格上；Ink/Stitch 在矢量多边形上做精确求交）。
  2. 错位针（staggers） — 相邻行的针位按 row_num / staggers % 1 错相， 并且错相以原点为绝对参考 —— 相邻色块拼接处针位完美对齐，这是我们像素方案天然欠缺的。
  3. pull_runs — 把可连通（垂直相邻）的段串成 run，避免每行都跳针；我们的「近距直针相连」是它的粗糙版。
  4. 随机针长抖动 — split_segment_random_phase：针长在 max_stitch_length 附近做受控随机， 消除肉眼可见的机械条纹，绣面更均匀。

03值得直接借鉴的设计

概念Ink/Stitch 做法优先级
底针（underlay） 填针前先绣一层稀疏底针（独立角度/行距/inset），固定面料、撑起面针。FillStitch.do_underlay 独立成组 下一迭代
锁针（lock stitch） 每段首尾/换色处加锁针防散线，可配置样式（ StitchGroup.lock_stitches ） 下一迭代
拉展补偿 pull_compensation（mm 或 %）外扩形状补偿面料拉扯；expand 参数补偿色块间缝隙 下一迭代
Stitch 元数据 Stitch 带 jump/trim/stop/color_change + tags（fill_row_start…）—— trim/stop 是真实机器控制 下一迭代
校验系统 每个元素 validation_warnings()：小形状警告（建议改走针/缎面）、形状非法、不连通、 expand 失败…带位置和解决步骤 —— 正是我们「检查面板」要长成的样子 下一迭代
缎面针 SatinColumn：沿中线骨架两侧往返 zigzag，auto_satin 可从填充分 shape 自动提取缎面柱 后续
矢量工作流 以 SVG 路径为源，用户直接编辑矢量形状；我们是位图限色 → 区域，可在量化后转矢量轮廓 后续
字库 lettering fonts/ 子模块 + lettering 扩展做刺绣字体 —— 刺绣软件的高频刚需 后续

04对 stitch.rs 的改造清单

  1. 引入 geo crate — 区域从像素标签图提取矢量轮廓（marching squares → 简化）， 之后扫描线求交、buffer 缩扩、合法性修复全部矢量精确化。
  2. 错位针 + 随机针长 — 先保持像素方案，把 stagger（4 行错相）和针长抖动移植过来，成本低收益大。
  3. 底针层 — 大色块填针前生成 45°/135° 稀疏底针，行距 2-3mm。
  4. 锁针 — 每色段首尾加 3 针小三角锁针。
  5. StitchPoint 扩展 — flag 增加 trim/stop；导出 DST 时 trim 映射为带剪线位的跳针。
  6. 检查项升级 — 参考其 validation：过小区域（<2mm² 建议走针）、细条（建议缎面）、超长跳线定位到坐标。
